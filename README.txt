AEIS 2027 — FULL WEBSITE + ADMIN HQ

This bundle contains both parts of the AEIS 2027 project:

1. aeis_2027_admin_hq/       — Admin HQ dashboard
2. AEIS_2027_Landing_Page/   — Public event landing page

IMPORTANT: Keep these two folders next to each other. The Admin HQ sidebar item called "The Event" opens:
../AEIS_2027_Landing_Page/index.html

HOW TO RUN:
1. Extract this complete ZIP.
2. Open the extracted AEIS_2027_Full_Project folder in VS Code.
3. Open aeis_2027_admin_hq/index.html with Live Server.
4. In the Admin HQ sidebar, click "The Event" to open the public landing page.
5. You can also open AEIS_2027_Landing_Page/index.html directly.

Both projects are front-end prototypes. Real registration storage, secure QR verification, Paystack and Admin HQ data syncing still require a backend and database. Paystack has intentionally not been connected yet.
